# Climb

Climb是一款基于CTDP的桌面浏览器专注工具。你可以为不同任务建立链条，约定开始动作、专注时长和中断规则，再用积累的专注节点沿着30座山峰攀登，在持续的专注过程中收获成就感和自我进步。欢迎前往https://www.ctdpclimb.site开始你的攀登之旅！！！

[在线体验](https://www.ctdpclimb.site)

## 主要功能

- 为学习、阅读等不同任务建立链条，每轮选择一个现实动作作为开始专注的标志。一次成功任务会为当前轮增加积累；失败后可以设置新一轮，重新开始。
- 设置任务内容与专注时长，选择立即开始或预约启动。同一时间只能有一个未完成任务，暂停、待判定和达标后尚未确认完成的任务也继续占用。计时按时间戳恢复，刷新或重开后可以继续处理，达标不会自动结算。
- 对中断或取消预约自行判定允许或违规。允许情境会形成当前轮的判例；正式中断判为允许后，任务保持暂停，由你主动继续。新轮可以选择继承历史判例。
- 查看任务结果、记录与往轮摘要，通过30座山峰观察专注积累。暂时不用的链条可以归档，之后恢复；永久删除会移除链条及关联记录。
- 无需登录即可使用当前浏览器的本地数据。新注册账户会带入游客数据，包括未完成任务；已有账户登录时下载云端完整数据，替换本机内容。声音设置也随账户保存。

## CTDP原理与来源

CTDP全称为Chained Time-Delay Protocol（链式时延协议）。本项目的设计思路来自Edmond在知乎[《如何提高自制力？》中的回答](https://www.zhihu.com/question/19888447/answer/1930799480401293785)。它用明确的承诺、连续成功的积累和可复用的例外规则，处理任务难以启动、执行中途放弃等问题。

### 神圣座位

提前约定任务要求，并选择一个明确的触发标志，例如戴上耳机。触发后，就按约定完成这次任务。连续成功让这条链积累信用，违规则使当前链归零，重新开始。这里的“座位”可以是动作或物品，约束的是主动开始后的任务时段；两次任务之间可以休息，不要求每天连续打卡。

### 下必为例

面对接电话、临时事务等中断，需要判断这类情况是否应被允许。若认定违规，当前链失败；若认定允许，就把它作为判例，之后在当前链的生命周期内遇到同类情况时也应允许。判断时需要考虑自己是否愿意持续接受这类例外，判例的情境边界也应足够明确。

### 线性时延

先承诺稍后启动任务，在预约与执行之间留出缓冲。原文通过独立的预约链约束按时启动，主任务链约束执行质量，预约后也可以提前开始。它试图让“同意稍后开始”成为较容易迈出的第一步，再用已经作出的承诺推动执行。

Climb将预约与专注组织在同一次任务中，没有照搬原文两条平行承诺链的结构。下面的时间节点换算与攀登路线也是本项目的设计，不属于CTDP原文定义。

## 攀登机制

成功任务的有效时间按完整分钟结算，余秒舍去，每30分钟换一个节点。不足30分钟的部分作为余量，留在同一链条的当前轮内继续累计，不跨链或跨轮合并。例如，同一轮先后成功专注20分钟和25分钟，会获得1个节点并留下15分钟余量；两条链各有20分钟余量时，总节点仍为0。

所有现存链条当前轮的节点合计决定攀登进度，包括归档链，不包括已经失效的旧轮和已删除链条。路线包含太阳系的30座山峰，第n峰对应累计20×n个节点：第一峰20个，第二峰40个，最后一峰600个。达到对应总节点即可登顶，不会额外扣除节点；完成全部山峰后仍可继续累计。

任务失败会使所在链条本轮的节点和余量归零，永久删除则移除该链对总节点的贡献，因此当前山峰可能回退。归档与恢复不改变进度。历史最高山峰和历史最高总节点独立保留，用来回看曾经达到的位置。

这些历史保留规则适用于单份数据。账户在不同设备间采用整份覆盖，旧副本上传仍可能降低云端历史纪录，不能保证跨设备的历史最高始终不变。

## 技术与工程

前端使用React、TypeScript、Vite和IndexedDB，后端使用Node.js 24、TypeScript、Fastify和SQLite。

| 目录 | 内容 |
| --- | --- |
| `web/` | 前端页面、业务逻辑和本地存储 |
| `backend/` | 账户、会话、业务快照和服务器校时 |
| `deploy/` | Windows构建打包、启动与版本切换脚本 |

本地运行与配置见[前端说明](web/README.md)和[后端说明](backend/README.md)。

## 使用说明

当前优先支持桌面浏览器。登录已有账户会用云端数据替换本机数据；账户修改经服务器确认后保存，断网时只读。多设备采用整份覆盖，可能丢失记录、恢复已删除内容或降低云端历史纪录，不提供自动合并和冲突保护。初版不提供密码找回或人工重置。
