## 目录与接口

| 目录 | 职责 |
| --- | --- |
| `src/app` | 启动编排、时钟注入、显式页面来源、列表访问状态、设置与写命令编排 |
| `src/pages` | P01—P06页面；P07暂保留占位 |
| `src/shared` | 共享设计变量、布局、按钮、图标、输入、开关、对话框与反馈 |
| `src/domain` | 无React及存储依赖的实体、任务状态、时钟与换算规则；相邻单元测试 |
| `src/data` | `Repository`接口、IndexedDB适配与存储测试 |
| `src/testing` | 可注入测试时钟、仅测试构建加载的工具 |
| `e2e` | Playwright浏览器验收 |
| `public` | 自托管现有字体、指定山景及Figma原始图标 |

使用具名类型、判别联合、TypeScript strict及无未使用变量检查；组件用PascalCase，函数和变量用camelCase。业务计算写纯函数，页面不直接操作IndexedDB。例如：

```ts
export interface Clock { now(): number }

export function reachedLevel(totalNodes: number): number {
  nonNegativeInteger(totalNodes);
  return Math.min(30, Math.floor(totalNodes / 20));
}
```

`Repository`提供 `initialize/readHome/setSound/get/writeAtomically/readChainState/executeChainCommand/executeTaskCommand/recoverTasks/close`。异步访问契约隔离页面与存储；未来远程服务适配该边界，暂不选后端供应商及同步协议。`writeAtomically`接受类型化add/put操作列表，统一事务完成才返回成功；不能将多个独立调用当成一笔业务事务。

实体预留链、轮次、任务、判定、判例及轮次关联、结算、设置、独立历史攀登纪录。业务实体ID采用UUID，记录含本地ownerId、可空accountId、创建及更新时间和必要关联；单例设置、元数据及任务占用采用稳定固定键。时间均用Unix毫秒时间戳，界面格式不反向参与计算。

任务判别状态区分预约、取消待判定、执行、正式中断待判定、允许暂停及终态。达标未完成为时长推导结果，不自动进入成功。时间函数按运行起点和累计有效时段计算；暂停与判定冻结，离线预约按原到期点补算。第三阶段已经接入实际任务命令与恢复；任务状态和结算规则集中在domain/task-rules及domain/task-commands。

IndexedDB当前版本为4：v4补充任务提醒标记、判定关联、暂停及正式开始时间；v3新增归档时间、失败摘要字段迁移、中断和复用候选表及关联索引；v1建立设置和归属元数据；v2建立业务表、按taskId唯一的结算索引和固定键任务占用。升级在versionchange事务内顺序执行，失败回滚。旧版夹具是测试数据，不表示曾发布过v1。打开或升级失败显示错误及重试；未知较新版本不降级、不清库。

结算索引与占用约束通过测试验证；正式业务仍须在后续阶段用事务内读取、校验和更新实现幂等结算。`put`不是幂等结算API，也不能直接用于抢占任务。第二阶段通过executeChainCommand实现受业务约束的整链级联删除；第三阶段通过executeTaskCommand实现正式结算及占用释放，页面不直接发出通用删除。

普通数据库名 `climb-local`，测试数据库名 `climb-testing`。初始化只写设置与本地归属元数据，不生成链条、任务、历史或山峰纪录。编译期常量决定模式，普通构建消除测试工具动态导入；URL参数不会切换。测试时钟不依赖真实等待，浏览器测试每次使用新上下文。

### 重开、暂停与异常边界

`recoverTasks`在启动读取页面前运行。刷新／重开先P01；运行时间依靠时间戳补算，定时器每250ms只刷新显示，且只在预约到期／首次达标时发出持久化tick，不逐秒写库或累加时间。预约到期后的正式起点取当前生效dueAt，取消判定主动关闭曾顺延的使用顺延dueAt；达标不自动结算。浏览器BFCache恢复也清空页面草稿、回首页并静默补算。

| 场景 | 数据与交互 |
| --- | --- |
| 取消预约时剩3分钟，在D04停留2分钟后主动关闭 | 仍剩3分钟，到期改为关闭时点＋3分钟；重复关闭不再顺延 |
| 取消预约D04中刷新／关页 | 草稿丢弃，remainingMs保持冻结；首页返回任务自动重开D04 |
| 正式中断D04主动关闭或刷新／关页 | 有效时间保持冻结；重开返回任务显示“处理本次中断”，不能直接继续或完成 |
| 判允许后暂停，刷新／关页 | 保持暂停；暂停等待包含判定期间，主动继续才恢复有效计时 |
| 运行专注／预约关闭后经过到期或达标 | 按原时间点补算；不补声音或旧到点条、不自动结算 |
| 任务数据丢失、损坏或关联无法可靠恢复 | 清理该次未结算任务、判定／中断及占用，不生成失败／历史／结果页；可恢复本轮累计、已生效判例、复用候选和既有历史保留 |

占用丢失但仅有一个可靠任务时可从任务恢复占用；无法确定唯一可靠任务时不猜选哪条继续。既有settlement不会被重复结算。恢复不会因正常关页、切后台或暂停过久自动判违规；不增加多标签操作权、广播或接管方案。

### 数据与状态边界

- `src/data/cloud-repository.ts`包装原IndexedDbRepository，页面经Repository及其account访问边界操作，没有在页面散落fetch。游客仍使用原本地命令；账户候选使用原planChainCommand/planTaskCommand计算，再整份上传，成功后才原子替换本机正式状态。声音设置走相同流程。
- IndexedDB升级至v5，新增account-control表，保留v1—v4迁移与业务数据。账户身份、服务器时钟锚点及单笔未确认请求在此保存；成功时业务集合、身份和待确认记录一起原子提交。快照编解码剥离本机归属和占用，导入时重建当前账户归属与唯一任务占用。
- 未确认保存固定operationId、候选快照、结算时刻及原命令结果，刷新后提供“处理未确认操作／重试原操作”。重试不重新生成ID、计时或结算。服务器已提交但本地写失败也保留原请求，重复确认后再提交本地。
- 注册初始请求、登录操作及退出也持久标记，结果未确认前保留原业务数据并阻止新修改；密码和Cookie不写入该表。注册或登录响应丢失后重开需重新输入原密码；已保存完整响应但尚未本地提交的情况可以再次校验会话和校时后完成。
- 未确认期间不允许继续积累业务修改或切换到另一账户；这是恢复单笔在途操作，不是离线业务队列。会话过期的未确认保存允许先显式重新登录原账户；不采用此次下载覆盖原候选，随后重试原操作。不同账户不能接管这笔请求。
- 旧请求有生命周期检查，关闭/重建Repository后迟到响应不能应用。退出经服务器确认后原子清空账户缓存、恢复空游客，云端快照保留。切换账户不自动成功或判违规。

### 校时、断网和任务恢复

`src/data/account-clock.ts`在账户模式采用服务器时间锚点＋performance.now经过时间。登录/注册完整响应后检查会话并请求time；已登录重开只查session及time，使用本机缓存，不GET业务快照。只有显式登录已有账户才下载业务数据；校时不伴随下载，也不逐秒请求。

账户校时失败或离线保持只读，不切到游客时钟开启写入；已有锚点维持计时展示。重开尚未校准时，用上次服务器锚点及本机经过时间作只读近似展示，存在本机时钟跳变误差，界面保持只读提示；必须重新确认会话和服务器时间后才能写。联网后在账户弹窗点击“检查会话并校时”，或会话失效时重新登录。

预约恢复使用原dueAt进入专注，暂停和两类判定冻结，达标不自动结算。启动恢复只作静默读投影，不上传、不补播旧提醒；正常用户命令仍按原业务层计算候选并等待服务器确认。关闭时未确认的业务修改保留原候选，不能简单按“关闭”推断成败。
